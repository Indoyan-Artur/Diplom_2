Stellar Burgers API — автотесты

Автотесты REST API сервиса Stellar Burgers
(https://stellarburgers.education-services.ru) на Python.

Что проверяется

- Регистрация пользователя (уникальный, повторная, без обязательных полей)
- Логин пользователя (успешный, неверные логин/пароль)
- Изменение данных пользователя (с авторизацией / без авторизации)
- Создание заказа (с авторизацией, без авторизации, без ингредиентов,
  с неверным хешем ингредиентов)
- Получение заказов пользователя (авторизованный / неавторизованный)
